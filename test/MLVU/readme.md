# MLVU

link:
- https://huggingface.co/datasets/MLVU/MVLU/
- https://modelscope.cn/datasets/AI-ModelScope/MLVU

support two sub-tasks in MLVU: `8_sub_scene`, `9_summary`

## how to use

1. run script `MLVU_generation.sh` to get all prediction answers.

2. run script `MLVU_evaluation.sh` to get all accuracy scores (gpt, bert, rouge).
